# TicTac Grapher

**ES** · Timegrapher acústico para relojes mecánicos (Android). Mide marcha, amplitud, error de latido y frecuencia con el micrófono del teléfono y da un diagnóstico del mecanismo con informe en PDF. App y documentación en español e inglés.

- **Página de descarga:** https://manursan2026.github.io/tictac-grapher/

# TicTac Grapher

Timegrapher acústico para relojes mecánicos (Android). Mide marcha, amplitud, error de latido y frecuencia con el micrófono del teléfono y da un diagnóstico del mecanismo con informe en PDF.

- **Descargar la app (APK):** [TicTacGrapher.apk](https://github.com/manursan2026/tictac-grapher/releases/latest/download/TicTacGrapher.apk)
- **Manual de usuario (PDF):** [manual.pdf](https://manursan2026.github.io/tictac-grapher/manual.pdf)
- **Página de descarga:** https://manursan2026.github.io/tictac-grapher/

Requiere Android 10 o superior.
